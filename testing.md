# Testing

## Purpose

This document records the planned tests, results and any fixes for the
Hair by Lydia website. Tests link back to the user stories and their
acceptance criteria.

## Testing approach

Testing will include checks for:

- Responsive layouts at 320, 768 and 1280 CSS pixels.
- Navigation, links and page content.
- Keyboard operation, visible focus and colour contrast.
- Image descriptions and form labels.
- Enquiry form validation and submission.
- Slideshow and review carousel controls.

These checks are planned and do not yet represent completed testing.

### Status key

- **Planned:** Test has been identified but not run.
- **Pass:** Actual result meets the expected result.
- **Fail:** Actual result does not meet the expected result.
- **Blocked:** Test cannot be run; record the reason.
- **Retest needed:** A fix has been made but not yet verified.
